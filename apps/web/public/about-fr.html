Vos agents, connectés à vos outils.

Agent Control est un produit de JemAI Labs. Utilisez vos agents Hermes depuis votre ordinateur ou votre téléphone, gérez les conversations et connectez les services de votre choix.

Ouvrir Agent Control

Connectez votre propre messagerie

Dans Paramètres → Plugins, choisissez Gmail ou Outlook. Connectez-vous sur la page du fournisseur, sélectionnez votre boîte et autorisez l’accès. Vous pouvez connecter plusieurs comptes et choisir les agents autorisés pour chacun. Hostinger et les autres services utilisent une connexion sécurisée IMAP/SMTP.

Vous contrôlez les accès

Les comptes connectés appartiennent à votre utilisateur Agent Control. Un agent ne peut accéder qu’aux comptes que vous lui attribuez. La rédaction prépare le texte dans la conversation ; l’envoi nécessite votre instruction explicite. Les nouvelles connexions sont disponibles dans une nouvelle conversation, avec votre ordinateur en ligne.

Traitement des e-mails

Agent Control chiffre les identifiants de connexion et traite les e-mails demandés pour les transmettre à l’agent choisi et à son fournisseur d’IA configuré. Les e-mails utilisés peuvent apparaître dans l’historique et les caches de conversation. Il ne s’agit pas d’un chiffrement de bout en bout. Déconnectez un compte dans Plugins pour retirer l’accès de l’agent. Contactez l’assistance pour les questions d’accès ou de suppression des données cloud.

L’accès à Gmail est actuellement limité aux testeurs inscrits à la bêta. Les comptes d’organisation peuvent nécessiter l’accord de leur administrateur.
